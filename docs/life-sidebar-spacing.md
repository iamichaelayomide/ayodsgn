# History spacing and sidebar polish

History uses the same page/card gutters, a compact title, smaller internal gaps and responsive padding. The card no longer touches the sidebar. Expanded and collapsed sidebar controls share icon dimensions, horizontal alignment and vertical spacing. Group chevrons are hidden in the collapsed desktop rail and restored in the mobile drawer, keeping the icon column centered. All sidebar content continues to scroll with the page or mobile drawer.

A dedicated blush/lavender organic-blob SVG replaces the nearly invisible ribbon overlay. The decorative asset is a CSS background and does not obstruct clicks or screen readers. The settings trigger, dialog title and accessible names now say Connections, with the existing link icon.

Verification: real page structure/styles checked in a local browser preview with mock history data, expanded desktop, collapsed desktop and 390px mobile drawer. JavaScript parsing, SVG XML parsing, updated labels and cache versions checked. No server data, history permanence rules or connection behavior changes. Browser preview has no console errors. Runtime asset versions: app 49, accounts 44, CSS 50, sidebar blob 1.
