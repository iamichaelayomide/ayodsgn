# Agent-led Opportunities release

## Behaviour
- Ramble supports atomic bulk tracking changes, custom pipelines and statuses from the current user instruction.
- Research uses four independent n8n workers, selected-company jobs, source-backed proposals and separately granted preparation-record writes.
- Daily discovery is bounded to 25 prospects across NYSC, Nigerian/international freelance, career and AI testing. No automatic messages or applications.
- Settings holds connection and selected CV/saved-email permissions. Credentials remain outside main research screens.
- Email composer supports attachments, contextual drafting, immutable owner-approved sending and duplicate/uncertain-send protection. Gmail OAuth remains a separate owner action.
- Compact email previews, anchored selects, contextual actions, inline date clearing and focused CV selection.

Browser verification uses the authenticated browser tool instead.
- n8n workflow safety and site validation pass. Five official CLI imports/export checks confirm inactive workflows, disabled connection gate and no selected credentials.

## Activation
No worker token or selected-context grant has been created by this release. Activation requires explicit owner approval at action time, credential selection and a bounded live execution. A local Mac worker cannot run while the Mac is asleep or powered off. Free Gemini allowance previously returned 429; successful live research must be verified before calling the connection operational.

## Execution decisions
The original 26 October plan prohibited deployment and credentials. Subsequent explicit user instructions authorize deployment and request broader agent access. Browser confirmation rules still apply to creating new access. Existing verified outcomes, manual notes and original CV files remain protected.
