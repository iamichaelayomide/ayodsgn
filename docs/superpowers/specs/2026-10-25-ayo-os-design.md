# Ayo OS initial module

The repository contains the portfolio AND Life: `.htaccess` maps life.ayodsgn.com to life/index.php. Work is limited to Life, its API, tests and documentation. The cached preceding chat contains reference placeholders rather than assistant content; the current user request and supplied Ayo profile are the available brief.

Integrate an owner-only Ayo OS view into Life using its fonts, buttons, sidebar, request helper, session, CSRF and PDO database. Preserve existing Opportunities and planner data. Store a separately versioned, tenant-keyed JSON snapshot following LifeApplications. No new service or credentials. Add an idempotent table migration; no production migration or deployment in this task.

Overview counts opportunities by pipeline and pending reviews. Opportunities have NYSC/Freelance/Career pipelines, company, title, stage, notes, portfolio/CV reference and follow-up date. Companies have industry, website and up to two contacts, each with professional email and provenance URL. Research notes distinguish cited observations from hypotheses; citations do not imply independent verification. Drafts link opportunities, contacts and source notes. Approval requires complete recipient provenance, sourced research, subject/body, materials reference, schedule with timezone and an explicit documents/content/recipient review. Immutable approval records snapshot all those values with actor, time and fingerprint. Any relevant edits invalidate the current approval. Rejection retains a reason and history. Drafted/approved never means sent; no sending, scheduling integration, provider export, automatic follow-up or external URL fetching.

Use bounded inputs, safe HTTPS links, escaped display, optimistic concurrency, tenant isolation and session cleanup. On conflict preserve unsaved form input and offer explicit reload. Manual research and draft authoring are intentional initial scope; AI agents and integrations remain future work. Avoid invented CVs, claims and addresses. Deliver feature branch and PR with verification evidence and known limitations.
