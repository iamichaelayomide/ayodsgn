# Ayo OS Implementation Plan

> **For agentic workers:** Use executing-plans to implement task by task.

**Goal:** Functional owner-only outreach workspace integrated into Life.
**Architecture:** Life session/CSRF gates, separate tenant-keyed versioned PDO snapshot, existing navigation and request helper. Immutable approval snapshots; no sending capability.
**Tech Stack:** PHP/PDO MySQL, vanilla JS modules, existing CSS tokens; SQLite tests.
**Spec:** docs/superpowers/specs/2026-10-25-ayo-os-design.md

## Global Constraints
- No automatic sending or production deploy.
- Preserve portfolio, planner and existing Opportunities records.
- Exact recipient, materials and schedule require explicit review.

## Review Focus
- Cross-account IDs must be unavailable.
- Concurrent writes must fail without losing local forms.
- Company/contact/research/draft edits must invalidate approvals.
- Malicious text and URLs must never execute.
- Logout and late responses must not reveal prior account records.
